데스커 벽고정 확인 (2026.10 개정 기준)
=====================================

설치할 데스커 상품을 골라 담으면 벽고정이 필요한지 알려주는 프로그램이에요.
설치 없이, 인터넷 연결 없이도 쓸 수 있어요.


[ 사용하는 방법 ]

1. 이 압축 파일을 풀어 주세요. (마우스 오른쪽 클릭 → "압축 풀기" 또는 "모두 압축 풀기")
2. "데스커_벽고정_확인.html" 파일을 더블클릭하세요.
3. 크롬이나 엣지 같은 인터넷 브라우저에서 열려요.
4. 위쪽 탭(책상세트 / 책장 / 옷장 / 제품코드로 찾기)에서 함께 설치할 상품을 모두 골라 담으세요.
5. 아래 "결과 보기"를 누르면 벽고정 필수 여부가 나와요.

  - 빨간 점이 붙은 상품은 "단독 설치 시 벽고정 필수" 상품이에요.
  - 함께 담은 상품에 따라 "연결 설치 시 권장"으로 바뀔 수 있어요.
  - 담은 상품은 내 PC 브라우저에만 저장돼요. 다른 사람에게 보이지 않아요.


[ 자주 묻는 것 ]

Q. 파일을 열었는데 메모장이나 코드가 보여요.
A. 파일에서 마우스 오른쪽 클릭 → "연결 프로그램" → Chrome 또는 Microsoft Edge를 골라 주세요.

Q. 압축을 풀지 않고 열면 안 되나요?
A. 압축 파일 안에서 바로 열면 담은 상품이 저장되지 않을 수 있어요. 꼭 압축을 풀고 열어 주세요.

Q. 글꼴이 조금 달라 보여요.
A. 인터넷이 안 되거나 막힌 곳에서는 기본 글꼴로 보여요. 기능은 똑같이 동작해요.


[ 참고 ]

참고용 안내예요. 실제 설치 가능 여부는 벽 상태와 설치 환경에 따라 달라질 수 있으니
시공 전 꼭 다시 확인해 주세요.

기준이 바뀌면 새 파일을 다시 받아서 쓰세요.


[ 사내 서버에 올리는 분께 ]

"서버배포용" 폴더에 Dockerfile이 들어 있어요. (nginx로 페이지 하나를 띄워요)
  docker build -t desker-wall-check .
  docker run -d -p 8080:80 desker-wall-check
